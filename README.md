# Öğrenme projeleri

Patika eğitimindeki haftalık C# / .NET / SQL ödevlerim (Ekim 2024 – Ocak 2025) ve üniversite ödevlerim. Her klasör
önceden ayrı bir depoydu; commit geçmişleri korunarak buraya taşındı.

Öne çıkan projelerim ayrı depolarda: [ECommerceBackend](https://github.com/BerkanGH/ECommerceBackend),
[BitirmeProjesi](https://github.com/BerkanGH/BitirmeProjesi), [MvcPatikaProjesi](https://github.com/BerkanGH/MvcPatikaProjesi).
